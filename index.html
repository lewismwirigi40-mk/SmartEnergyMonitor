Smart Energy Monitor

A simple digital twin that simulates voltage, current, and power readings for a Kenyan 230V grid and displays them in real time.

Nyeri, Kenya Python + Matplotlib Live Simulation

What It Does

The system generates simulated sensor readings, calculates power, and updates a live dashboard continuously.

Core Features

  • Simulated voltage and current readings
  • Real-time power calculation
  • Live console output
  • Matplotlib dashboard charts

Quick Start

Run It Locally

  1. Install dependencies with pip install -r requirements.txt
  2. Start the app with python main.py
  3. Watch the live readings and graphs update every second
