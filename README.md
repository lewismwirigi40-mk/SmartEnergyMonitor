# Smart Energy Monitor - Digital Twin

**Developer:** Lewis Mwirigi  
**Location:** Nyeri, Kenya  
**Type:** Full Software Simulation (No Hardware Required)

A real-time energy monitoring system that simulates Kenyan 230V grid readings, calculates power from voltage and current, and displays live console output with synchronized Matplotlib graphs.

## Features

- Simulated voltage and current readings
- Real-time power calculation
- Live console dashboard
- Live Matplotlib charts for voltage, current, and power
- Pure Python implementation for portfolio/demo use

## How to Run

1. Install dependencies:
   `pip install -r requirements.txt`
2. Start the monitor:
   `python main.py`

Press `Ctrl+C` to stop the simulation safely.
